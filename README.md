# peakjar-data (archived)

This repository is no longer maintained. PeakJar's peak catalogue and mountain
regions are now built together with the map tiles, from the same
OpenStreetMap snapshot, in
[getpeakjar/peakjar-maps](https://github.com/getpeakjar/peakjar-maps), and
published as its `data-YYYY-MM-DD` releases.

The files here (`geo/polish_peaks.json`, `geo/polish_regions.json`, release
`v0.1.0`) are the original Poland-only export from Overpass Turbo, kept for
reference. Data © OpenStreetMap contributors, available under the
[Open Database License](https://www.openstreetmap.org/copyright).
